# Best Practices Repository for Placement Preparation

A centralized, full-stack Knowledge Management System designed to help college students prepare for campus placements. This platform allows users to search, filter, read, and manage interview preparation materials, coding resources, and placement experiences.

## 🚀 Features
*   **Authentication & Authorization:** Secure JWT-based login system with distinct Student and Admin roles.
*   **Knowledge Base Search:** Real-time search and category filtering for quick access to resources.
*   **Rich Article Management:** Create, edit, and delete placement articles with automatic view tracking.
*   **Cloud Document Storage:** Upload and view supporting documents (PDFs, PPTs, Docs) powered by Cloudinary.
*   **Admin Dashboard:** Platform analytics and user role management for system administrators.
*   **Responsive UI:** Mobile-friendly interface built with React and Vite.

## 💻 Technology Stack
*   **Frontend:** React.js, Vite, React Router, Axios, Lucide Icons, plain CSS.
*   **Backend:** Node.js, Express.js, JWT Auth, Multer.
*   **Database:** MongoDB Atlas (Mongoose).
*   **File Storage:** Cloudinary.
